# Happy Birthday Project

Một dự án dành cho chúc mừng sinh nhật (Happy Birthday).

## Mô tả (Description)
Dự án này chứa các tài nguyên và mã nguồn phục vụ việc tạo trang web/ứng dụng chúc mừng sinh nhật.

## Danh sách tệp (Files)
- `login.png`: Hình ảnh giao diện đăng nhập/tài nguyên dự án.

## Hướng dẫn kết nối GitHub / GitLab (Remote Repository)
Để đẩy repository này lên GitHub, bạn thực hiện các lệnh sau trên Terminal / Command Prompt:

```bash
# 1. Liên kết đến repository từ xa trên GitHub (Thay URL bên dưới bằng URL repo của bạn)
git remote add origin https://github.com/USERNAME/happy_birthday.git

# 2. Đẩy mã nguồn lên branch main
git push -u origin main
```
